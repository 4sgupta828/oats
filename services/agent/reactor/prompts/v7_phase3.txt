**Objective:** Prove the causal mechanism of your top hypothesis (confidence > 0.90).

You arrive here with a high-confidence hypothesis. Now validate *how exactly* the failure occurred.

## Strategy: Prove the Mechanism

Phase 2 gave you **what** is anomalous. Phase 3 must explain **how** it failed.

**Questions to answer:**
- What is the specific failure mechanism?
- Can you trace the causal path from root cause to symptom?
- Do you have multiple pieces of corroborating evidence?

**Example:**
- **Phase 2 finding:** Cache hit ratio collapsed 74.5%
- **Phase 3 goal:** Prove *why* it collapsed
  - Hypothesis: Eviction policy bug
  - Evidence needed: Eviction rate spike, premature evictions of valid entries
  - Tools: `get_cache_stats()` + custom log parsing to show which keys evicted

## When to Write Custom Scripts

**Write a custom script when:**
1. **Correlating request IDs** across multiple log files
2. **Parsing non-standard formats** (custom log formats, debug output)
3. **Custom statistics** (p99 latency from raw log lines, percentile calculations)
4. **Multi-step analysis** requiring state tracking
5. **Complex filtering** beyond what grep/rg can do

**Example Use Case:**
```python
# Trace a specific request through multiple services
# Script: trace_request.py

import json

request_id = "req-12345"
services = ["api-service", "user-cache", "database-1"]

for service in services:
    with open(f"logs/{service}.jsonl") as f:
        for line in f:
            log = json.loads(line)
            if log.get("request_id") == request_id:
                print(f"[{service}] {log['timestamp']}: {log['message']}")
```

**Workflow:**
1. `create_file("trace_request.py", script_content)`
2. `shell("venv/bin/python3 trace_request.py")`

## Causal Mechanism Validation

**Strong validation requires:**
1. **Statistical evidence** (from Phase 2)
2. **Mechanistic evidence** (from Phase 3)
3. **Temporal correlation** (timing aligns)
4. **Logical coherence** (mechanism makes technical sense)

**Example of Complete Validation:**
```
Hypothesis: user-cache v1.2.3 eviction bug

Statistical Evidence (Phase 2):
- cache.hit_ratio: 98% → 25% (z=12.3, STEP_CHANGE at deployment)
- cache.eviction_rate: 10/sec → 750/sec (z=5.2)

Mechanistic Evidence (Phase 3):
- get_cache_stats(): total_evictions spiked 75× baseline
- Log analysis: New log template "EvictionPolicy: invalid TTL calculation"
- Custom script: Parsed cache debug logs, found 90% of evicted entries had valid TTLs

Temporal Correlation:
- All anomalies started within 5 seconds of deployment at T-3min

Logical Coherence:
- TTL calculation bug → premature evictions → low hit ratio → high DB load → API latency
```

## Phase Transition

**Exit Criteria (Promotion to Phase 4):**
✓ You can explain *how* the failure mechanism works
✓ You have multiple pieces of corroborating evidence
✓ The mechanism is technically plausible and coherent

**When criteria met:**
- Update `state.active.phase = "CAUSAL_CONFIRMATION"`
- In `strategize.reasoning`: "Causal mechanism confirmed: [explain mechanism]. Transitioning to Phase 4 to verify this component is the source, not a victim of upstream failure."

**Stuck Criteria (Regression to Phase 2):**
✓ Cannot confirm mechanism after 5+ turns
✓ Evidence contradicts the hypothesis
✓ Deep validation reveals hypothesis was wrong

**When stuck:**
- Update `state.active.phase = "EVIDENCE_GATHERING"`
- In `strategize.reasoning`: "Unable to confirm mechanism for H1. Returning to Phase 2 to test H2 or generate new hypotheses."
- Reduce confidence of current hypothesis
- Mark hypothesis as "RULED_OUT" if contradicted

## Common Mistakes

**Mistake 1: Stopping at statistical evidence**
- Phase 2 shows *what* is anomalous
- Phase 3 must explain *how* the failure occurred
- Don't skip mechanism validation

**Mistake 2: Not using custom scripts when needed**
- Standard tools may not answer all questions
- Don't be afraid to write Python scripts for deep analysis

**Mistake 3: Weak corroboration**
- One piece of evidence is not enough
- Gather multiple independent pieces that support the mechanism

**Mistake 4: Ignoring alternative explanations**
- If evidence contradicts hypothesis, acknowledge it
- Don't force-fit evidence to match your preferred hypothesis
